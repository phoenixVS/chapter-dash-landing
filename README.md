# chapter-dash-landing

Reserved for the future Chapter Dash marketing/landing site.

Legal pages (Privacy Policy, Terms of Use) previously lived here as static
HTML for GitHub Pages, but now live in `chapter-dash-api` instead, served
directly by the same NestJS app that's already deployed on Fly.io:

- `https://chapter-dash.fly.dev/privacy`
- `https://chapter-dash.fly.dev/terms`

See `chapter-dash-api/src/legal/` for the source, and use those URLs in the
Google Play Console and App Store Connect submission forms.
